---
description: Standard TDD Development Workflow: Issue -> Branch -> TDD -> Implement -> Verify -> Confirm -> Push/PR -> Merge
---

1. **Create Issue**: Create a GitHub issue for the task.
2. **Create Branch**: Create a new branch for the task.
3. **TDD (Write failing test first)**: Write a failing test case that defines the expected behavior.
4. **Implement Code**: Write the specific code to satisfy the test.
5. **Verify Test (Pass)**: Run tests to ensure they pass.
6. **Wait for User Confirmation**: DO NOT PROCEED until the user confirms the implementation is OK.
7. **Push & PR**: Push the branch and create a Pull Request.
8. **Merge**: Merge the PR.
